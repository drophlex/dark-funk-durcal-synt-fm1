3 Send it to the FM-1 tracks

FM-1 trackgets this part of the fileas drums
Steps are 1/16 notes: the file is quantized to the FM-1's grid (up to 4 notes per step, ties for long notes, accents from loud notes, slides from overlapping notes). A MIDI file holds the notes, not the sound: the sound is the FM-1 track's preset. For the "exact" sound, pick the same preset (the pack's files are named after the RITUAL styles: SUMMON that style first, then write the file over it).
